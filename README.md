# vibe-demo

A 10-line Express app. The fastest way to see [Vibe](https://github.com/abicevoice1-sudo/vibe) work:

```bash
npx -y abicevoice1-sudo/vibe abicevoice1-sudo/vibe-demo
```

Vibe clones it, detects Node, runs `npm install`, picks `npm start`, grabs a free port — and hands you a URL. Seconds, no config.
